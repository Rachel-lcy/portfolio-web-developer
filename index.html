AI Resume Analyzer

Personal project · Designed and built solo

A web app that compares a resume PDF with a job description and shows match scores, matched and missing skills, and AI-generated suggestions.

  • Built the resume upload form and a results page that displays scores and skill comparisons
  • Wrote server-side API routes that extract text from the PDF and send it, with the job description, to an AI model on Amazon Bedrock
  • Kept AWS credentials on the server in environment variables, so no keys are exposed in the browser

Tools: Next.js · React · Tailwind CSS · Amazon Bedrock · pdfjs-dist · Vercel

Education

SAIT — Interactive Design, Web Design & Development

I'm a Calgary-based web developer and a 2025 graduate of SAIT's Interactive Design — Web Design & Development program. Through coursework and personal projects, I've built web apps with user sign-in, payments, content management, and an AI-powered resume analyzer. I enjoy turning an idea into a working interface and tracking down what's wrong when something breaks.

Before SAIT, I spent four years in product and operations in China, working with customer feedback, website requirements, and teams across the business. It taught me to ask questions, clarify requirements, and keep the people using a product in mind.

I also practise IT support in a home lab and volunteer as a tech mentor for older adults, which helps me troubleshoot patiently and explain technical steps clearly. I'm bilingual in English and Mandarin, and I'm looking for a team where I can contribute, learn from experienced developers, and keep growing.
